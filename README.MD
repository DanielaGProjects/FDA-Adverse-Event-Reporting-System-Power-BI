# Clinical data adverse effects and MedDRA dictionaries project

This repository is part of a project portfolio designed to showcase data analytics and modeling capabilities.


## Data source
The data was fetched using OpenFDA API and Python. Here is the reference to  [OpenFDA API](https://open.fda.gov/apis/). 

## Field of study
This project aims to study Adverse effects reported and published by FDA in 2019 involving corticosteroids.

## Report 
The data will be analyzed using Power BI
